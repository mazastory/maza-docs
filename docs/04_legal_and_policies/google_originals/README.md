# 구글 원문 스냅샷

> **이 폴더가 정본이다.** 같은 주제의 한국어 요약 문서(`../01_…`, `../02_…`)와 바탕화면·`legal/` 의 옛 사본은 **요약이거나 옛 판**이고,
> 그중 일부는 구글이 하지 않은 말을 섞어 놓았다(2026-10-08 정정). 원문과 다르면 **원문이 맞다.**

| 파일 | 출처 | 보관 방식 |
|---|---|---|
| `search-spam-policies.md` | developers.google.com/search/docs/essentials/spam-policies | **원문 전문** (CC BY 4.0) |
| `search-using-gen-ai-content.md` | …/fundamentals/using-gen-ai-content | **원문 전문** (CC BY 4.0) |
| `search-creating-helpful-content.md` | …/fundamentals/creating-helpful-content | **원문 전문** (CC BY 4.0) |
| `search-blog-2023-ai-content.md` | …/search/blog/2023/02/google-search-and-ai-content | **원문 전문** (CC BY 4.0) |
| `INDEX.json` | 애드센스 자격 요건·프로그램 정책·게시자 정책(복제 콘텐츠·저가치 화면) | **지문만** — 구글 도움말은 저작권 표시이므로 본문을 복제하지 않는다. 링크를 열어 읽는다 |

- 원문은 **수정·요약·번역하지 않았다**(HTML 을 글자로 바꾼 것뿐). 머리 주석에 출처·받은 날·지문이 있다.
- **구글이 문서를 바꿨는지** 확인: `python3 snapshot.py --check` (지문이 달라진 문서를 알려준다). 바뀌면 `python3 snapshot.py` 로 다시 받고, 이 폴더의 요약 문서를 원문에 맞춰 고친다.
- 마지막으로 받은 날: **2026-10-08**.
- 인용 규칙: 구글의 말이라고 쓰려면 **이 폴더의 원문에서 문장을 찾을 수 있어야** 한다. 못 찾으면 "구글이 한 말"이라고 쓰지 않는다.
